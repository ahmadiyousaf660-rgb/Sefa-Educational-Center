SEFA Educational Center - GitHub Upload Pack

Upload the CONTENTS of this folder to the GitHub repository root.
Do NOT upload a real .env file or any OpenAI API key.

Main files:
- index.html
- server.js
- package.json
- render.yaml
- manifest.webmanifest
- sw.js
- sefa-logo.svg
- icons/icon-192.svg
- icons/icon-512.svg
- .env.example
- .gitignore

For Render:
Build Command: npm install
Start Command: npm start
Environment variables:
OPENAI_API_KEY = your secret API key (add only in Render, never GitHub)
OPENAI_MODEL = gpt-5-mini

After deployment, Render provides a public HTTPS website URL. The PWA can then be installed on Android.
